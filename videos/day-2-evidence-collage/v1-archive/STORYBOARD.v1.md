## Story spine (v2 — user at the center)

The viewer is a developer. **They** are the protagonist; the Courier (fondof) works FOR them.
The lore, told explicitly in narration: three real sources — Paul Graham's *Schlep Blindness* essay,
Peter Thiel's competition talk, kepano's moats thread — are forged into ONE skill that does real,
customised work in a real repo (`skill-share.ts` source-route). The video ends by handing the tool to the viewer.

## Recurring cast & motifs (Day-1 lesson: characters, not documents)

- **You, the developer** — a desk/workspace motif. Frame 1: overwhelmed by clone cards. Frame 7: the same desk, one fitted skill, in control. Visual bookend.
- **The Courier** (forger-courier-cutout.png) — fondof's agent persona. Grayscale halftone + coral offset shadow, lower-frame foreground crop (Vox pattern). Appears in every frame doing a verb: gathering, forging, stamping, delivering.
- **The Clone** — a generic skill card with a face (reused clone motif), the antagonist of Frame 1 and Frame 5.
- **The Source Hand** (source-hand-cutout.png) — the hand of provenance; hands the three sources to the Courier (Frame 3), stamps the receipt (Frame 6).
- **The three sources as distinct shapes**, recurring across frames:
  - PG essay = long cream text-strip (real screenshot crop)
  - Thiel talk = dark video card with play triangle (real capture)
  - kepano moats = stacked thread cards (real capture)
- **Coral route line** — connects source → forge → repo across frames; becomes the URL band in Frame 7.

## Staging rules (from Day 1)

- Structure first, then people: paper/props settle before characters enter.
- FG occlusion: at least one prop overlaps each character so it sits IN the world.
- One focal per beat; evidence/functional type stays still while read.
- Coral rationed: ≤2 coral moments per frame (route + one accent).

## Revision contract
- **Mobile hierarchy:** one readable factual primary per spoken clause; supports never compete with it.
- **Asset integrity:** real screenshots for PG/Thiel/kepano/off-chain draft. Off-chain draft only in Frame 5, labelled `OFF-CHAIN / NOT USED`. No fake metrics, no fake "published".
- **Route discipline:** coral routes run through clear gutters only.

## Frame 1 — Your feed is flooded (~7s)
- voiceover: "Every AI can generate a skill now. And most of them are garbage. Hallucinated imports. Fake APIs. Written for no one. Fitted to nothing."
- focal: rain of identical clone skill cards.
- staging: developer desk at bottom (workspace silhouette); generic skill cards ("5 TIPS", "AUTO CODE", "BEST PRACTICES") tumble/stack chaotically. The Courier watches from lower-left, arms-crossed crop, unmoved.
- motion: cards drop in staggered steps; one card's fake import line glows red briefly.

## Frame 2 — The question (~4s)
- voiceover: "So what makes one worth keeping? What if it started with thinking that already survived?"
- focal: the typed question + marker on "worth keeping?".
- staging: clone cards sweep away, leaving clean graph-paper desk. Question types on in the prompt strip; big Outfit question lands; Courier steps forward (transition into Frame 3).

## Frame 3 — Three real sources (~8s)
- voiceover: "Paul Graham, on the work everyone skips. Peter Thiel, on why competition is for losers. Kepano, on how moats actually stack. Three sources. Real thinking. Not vibes."
- focal sequence: PG strip → Thiel video card → kepano thread stack (each named in a label as the VO names it).
- staging: the Source Hand passes each clipping in from the right edge; the Courier pins each to the desk as it arrives. Real screenshot crops, tape + torn edges.
- motion: three stepped arrivals synced to the three names; each settles still while read.

## Frame 4 — The forge (~5s)
- voiceover: "fondof forged them into a single skill. Fitted to this repo. But the first draft? It looked convincing."
- focal: three clippings fold into a press/forge; a single skill card emerges — then a second, shadier copy (the Clone) slides out too.
- staging: Courier works the press; coral route line runs source → press → card. Repo tag `fondof/` sits on the press.
- motion: collapse-in, press beat, card out; ominous hold on the Clone copy.

## Frame 5 — Rejected (~6s)
- voiceover: "Then the fit review caught invented imports and fake references. Rejected. No mercy."
- focal: real off-chain draft crop + redline slips + REJECTED stamp.
- staging: dark review mat; draft labelled `OFF-CHAIN DRAFT / NOT USED`; two redline slips (INVENTED IMPORT, FAKE REFERENCE) land one at a time; Courier slams the stamp, then flicks the Clone off-frame.
- motion: crop locks → slips on stepped holds → stamp resolves (half-beat pause after "Rejected.") → clone exits.

## Frame 6 — The re-forge + proof (~8s)
- voiceover: "So we went back to the source. Followed the actual trail. Into this codebase, out the other side as a skill that actually fits."
- focal: real `skill-share.ts` source-route lines on the navy code surface, provenance receipt beside it.
- staging: coral route traces PG strip → code panel → receipt. Source Hand stamps `PROOF / SIGNAL / USE` on the receipt. Tabs show the three sources retained as provenance.
- motion: route draws, code lines type/lock, receipt slides up, stamp lands.

## Frame 7 — Your turn (~7s)
- voiceover: "That developer? That's you. Don't install the skill. Re-forge the thinking. fondof dot netlify dot app."
- focal: strike-through "DON'T INSTALL A SKILL." → "RE-FORGE THE THINKING." + coral URL band.
- staging: bookend of Frame 1 — same desk, now tidy: one fitted skill card in place, Courier hands it toward camera (toward YOU). URL band is the final coral moment.
- motion: strike draws, replacement rises, URL locks. Stillness during the URL read. No captions.
